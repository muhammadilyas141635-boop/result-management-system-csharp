# 🎓 Student Result Management System (C# Console Application)

## 📌 Overview
The Student Result Management System is a simple console-based application written in C#. It helps manage student records, including marks, percentage, and grades.

This project is ideal for beginners to understand basic programming concepts such as arrays, loops, functions, and classes.

---

## 🚀 Features

- ➕ Add new student
- ❌ Remove student
- ✏️ Update student details
- 📋 View all students
- 🔍 Search student by Roll Number
- 🏆 Show topper student
- 📊 Calculate subject averages
- 📈 Display grade distribution

---

## 📊 Grading Criteria

| Percentage | Grade |
|-----------|------|
| 80 and above | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

## ▶️ How to Run

1. Open the project in **Visual Studio** or **VS Code**
2. Build the project
3. Run the application
4. Use the menu options (1–9) to interact with the system

## ⚠️ Limitations

- Maximum 100 students (fixed array size)
- Data is not stored permanently (no database/file storage)
- Console-based UI only
